# CPE009B-Final-Project
📖 About<br>

The Orbit company handled payslips manually, which was slow and prone to computation errors. This project automates the process with a Python program that computes employee salaries and generates payslips.<br>

HR enters the employee's details, days worked, overtime, holiday work, night shifts and tardiness for a cutoff period. The system then calculates gross pay, subtracts the deductions (SSS, Pag-IBIG, PhilHealth, tax, tardiness) and shows the net pay on a printable payslip, making payroll faster and more accurate.<br>
<br>
✨ Features<br>
Role-based login — HR and Manager accounts see only the tabs they are allowed to use.<br>
Employee management — add and edit employees and their SSS, PhilHealth, Pag-IBIG and TIN numbers.<br>
Attendance encoding — days worked, absences, late minutes, overtime, night differential and holiday work per cut-off.<br>
Automatic computation — earnings, deductions, government contributions, withholding tax and net pay.<br>
Live payslip preview — the payslip updates as you type, before anything is saved.<br>
PDF export — save any payslip as an A4 PDF.<br>
Approval workflow — saved payslips start as drafts and are approved by a manager.<br>
Editable settings — company details, pay rates and contribution tables are edited in the app, with no code changes.<br>
Optional 13th-month pay — include it when generating a payslip.<br>
