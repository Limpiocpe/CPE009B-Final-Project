# CPE009B-Final-Project
CPE009B Final Project: Payslip System <br>

A desktop payroll app for Philippine employees, built with Python, Tkinter and SQLite. It computes semi-monthly (kinsenas) payslips, including overtime, night differential, holiday pay, SSS, PhilHealth, Pag-IBIG and withholding tax. Users sign in as HR (manage employees, generate payslips, edit settings) or Manager (review and approve payslips). Payslips are shown as a live preview and can be exported to PDF.
